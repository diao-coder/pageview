01 / 功能

一个应用，取代一整套工具。

媒体嗅探

打开网页，XIDM 就在后台识别其中的视频、音频与 HLS 播放列表。底部的计数气泡告诉你这一页抓到了几个，点一下即可下载。每个标签页独立识别，互不干扰。

3
  • HLS master.m3u8 1080p
  • MP4 trailer.mp4 48 MB
  • M4A audio.m4a 6.7 MB

多线程分段下载

按 Range 把文件切成多段并行下载，断网、杀进程后自动从断点续传；失败时按退避策略自动重试。

HLS 一键成片

自动选最高码率与默认音轨，支持 AES-128 加密与 fMP4，下载完成后用 FFmpeg 无损合并成可直接播放的 MP4。

BT 与磁力链接

基于 libtorrent 引擎，导入 .torrent 或粘贴磁力链接即可下载，支持下完做种、IP 过滤与独立的限速。

广告拦截，规则由你定

内置 AdAway 列表，可添加在线 Hosts 源或导入自己的文件；域名及其子域名一并拦截，自定义白名单优先生效。只走 https 下载列表，防篡改。

隐身窗口

在独立进程与独立存储中浏览，不留历史；关闭窗口即清除 Cookies、缓存与网站数据。

智能剪贴板

复制一个文件直链或磁力链接，回到 XIDM 就会提示下载。只保存链接的哈希前缀，从不保存链接本身。

精细控制

全局或单任务限速、仅限 Wi-Fi、低电量暂停、HTTP / SOCKS5 代理、调整排队顺序、复制移动与重下选项。

让 AI 代理帮你下载

开启后，XIDM 在本机提供 MCP 接口，电脑上的 AI 代理可以查看、添加和管理下载。每个连接独立令牌、按权限分级，默认只监听 127.0.0.1，绝不返回 Cookies、凭据与浏览历史。

02 / 引擎

从链接到文件，每一步都看得见。

  1. 01

    探测

    识别文件名、大小、是否支持断点；4xx 视为永久错误，不浪费重试。

  2. 02

    规划

    按大小切分 Range 段，HLS 选最高码率变体与默认音轨。

  3. 03

    并行抓取

    多段同时下载，令牌桶精确限速，进度定期落盘，进程被杀也能续上。

  4. 04

    合并成片

    FFmpeg 只做流复制、不转码：时间轴对齐、音轨不丢，输出秒开的 MP4。

03 / 隐私与安全

你的下载，只属于你。

没有广告 SDK，不卖数据。下载任务、历史、书签与设置都只留在你的设备上。

阅读隐私政策 →
  • 统计可关闭匿名使用统计只含预定义事件，绝不包含网址与文件名，一键关闭并清除。
  • 安装包自校验启动时校验签名证书，被重新打包的版本会拒绝运行。
  • 证书固定的更新更新与配置走证书固定的 HTTPS，安装前核对大小、SHA-256 与签名。
  • 组件不对外暴露进程间通信使用签名级权限，其他应用无法调用 XIDM 的下载服务。
  • Cookies 不外泄网页 Cookies 只发给原站点，跨站重定向即丢弃；拒绝 HTTPS 降级到 HTTP。

    该选哪个？
    • arm64-v8a：近几年的绝大多数手机和平板（64 位 ARM）。
    • armeabi-v7a：较老的 32 位 ARM 手机。
    • x86_64：模拟器、部分 Chromebook 与 Intel 平板。
    • 通用包：包含全部架构，任何设备都能安装，体积最大。
    怎样校验文件？

    下载后计算 SHA-256，与上面列出的值一致才说明文件完整、未被篡改。

    certutil -hashfile xidm.apk SHA256      # Windows
shasum -a 256 xidm.apk                  # macOS
sha256sum xidm.apk                      # Linux
